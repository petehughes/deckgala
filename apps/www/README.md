# `@deckgala/www`

Responsive DeckGala marketing site describing offline pool-deck timing and the
connected club workflow. It uses the shared DeckGala color tokens and is
deployed as a standalone Vercel workspace.

Run locally with:

```powershell
bun run --filter @deckgala/www dev
```

Set `NEXT_PUBLIC_SITE_URL` in the deployment environment when the site uses a
custom canonical domain.
