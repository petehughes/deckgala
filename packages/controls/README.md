# `@aquateamhub/controls`

Shared React controls, DeckGala brand tokens, and Tailwind CSS v4 theme mappings.

- Import `@aquateamhub/controls/tailwind.css` in a Tailwind v4 app stylesheet.
- Import `@aquateamhub/controls/styles.css` for the shared `LaneCard`,
  `TimerDisplay`, and `StopButton` component styles.
- Import `LaneCard`, `StopButton`, or `TimerDisplay` from `@aquateamhub/controls`.

The current timer app uses the shared brand variables directly from
`@aquateamhub/controls/tokens.css`.
