# `@deckgala/controls`

Shared React controls, DeckGala brand tokens, and Tailwind CSS v4 theme mappings.

- Import `@deckgala/controls/tailwind.css` in a Tailwind v4 app stylesheet.
- Import `@deckgala/controls/styles.css` for the shared `LaneCard`,
  `TimerDisplay`, and `StopButton` component styles.
- Import `LaneCard`, `StopButton`, or `TimerDisplay` from `@deckgala/controls`.

The current timer app uses the shared brand variables directly from
`@deckgala/controls/tokens.css`.
